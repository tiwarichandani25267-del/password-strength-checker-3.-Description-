# Password Strength Checker

**Project:** IBM SkillsBuild Cyber Security BootCamp 2026  
**Project type:** Python command-line security awareness tool

## Overview
Password Strength Checker gives an educational assessment of a password using its length, character variety, a small common-password blocklist, repeated characters, and simple predictable sequences. It returns a rating and practical feedback.

## Features
- Hidden terminal input using Python's `getpass` module.
- Checks length, lowercase, uppercase, digits, and symbols.
- Flags a small built-in list of common passwords.
- Detects simple sequences and all-one-character passwords.
- Displays a rough character-pool entropy estimate.
- Does not save, transmit, or log the entered password.
- Uses only Python's standard library.

## Run the project
1. Install Python 3.9+ from https://www.python.org/downloads/ if it is not installed.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. (Optional) create and activate a virtual environment.
5. Install the listed requirements:
   ```bash
   python -m pip install -r requirements.txt
   ```
6. Run:
   ```bash
   python Chandani_Tiwari_PasswordStrengthChecker.py
   ```
7. Enter a sample/test password when prompted. Terminal input is hidden.

On some systems, use `python3` instead of `python`.

## Example
The exact score depends on the input. For a weak test password, the tool may recommend using 12 or more characters and adding character variety. Do not paste your real account password into demonstrations or screenshots.

## Methodology
The program awards points for six simple checks and applies penalties for certain predictable patterns. It then maps the score to a descriptive rating. The entropy figure is a rough mathematical estimate based on the character categories present.

## Limitations
- The common-password list is intentionally small and is not a breach database.
- It does not detect every dictionary word, personal-information pattern, or password reuse.
- The entropy estimate assumes a simplified character pool and does not model human choices.
- The result is educational guidance, not a formal security guarantee. Long, unique passwords or passphrases generated by a reputable password manager are recommended.

## Dataset
No external dataset is used. The project includes a small illustrative blocklist in the source code.
